# Heap Sort Visualizer

An interactive web application that demonstrates the Heap Sort algorithm through visual animations and step-by-step execution.

## Features

- Interactive Heap Sort Visualization
- Dynamic Array Generation
- Step-by-Step Sorting Process
- User-Friendly Interface
- Frontend and Backend Integration

## Technologies Used

### Frontend
- React
- Vite
- CSS

### Backend
- Node.js
- Express.js

## Project Structure

```text
Heap Sort
│
├── src
├── public
├── Backend
└── assets
```

## Installation

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd Backend
npm install
node server.js
```
